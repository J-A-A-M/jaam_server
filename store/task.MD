#Задача
створення інтернет-магазина

#Загальні деталі
використати вже наявний дизайн з модуля web_server
база даних - sqlite, але закласти можлтвість перейти на іншу sql-базу
систему оплати реалізувати до рівня корзини з введеням всіх даних по відправці і кнопкою "оплатити", саму оплату не робити, просто зберігати замовлення в статусі "нове"

#юзер-частина
реєстрація - через email/password без підтвердження, відразу логінити
дані для відправки - прізвище імʼя та по батькові, місто, селект-бокс відділень новой пошти (заглушка, реальні відділення підключимо пізніше)
зберігання корзини по кукісам
мати кабінет з списком замовлень

#admin-частина
адміном стає будь-який юзер, який вводить мастер ключ або згенерований ключ в спеціальне поле
мастер ключ для адмін частини задається в конфігурацїї - просто текстове поле з довгим ключем, ввівши який бзер сайта стає адміном
кожен адмін може прибрати флаг адміна з іншого адміна
кожен адмін може згенерувати ключ для створення  адміна, який буде збережений в базу і помічений як використаний, з вказанням, хто і коли його використав

##редактор статусів замовлень
зробити можливість редагувати статуси і flow замовлень.  одна загальне flow для всього

##редактор замовлень
список замовлень з усіма даними - хто замовив, що замовлено і з якими модифікаціями товару
можливість рухати замовлення по flow - в певному статусі мати кнопки для переводу в наступий крок flow
на будь якому кроці мати можливість сказування замовлення - перевод в статус "скасовано"
статуси "нове" "завершене" та "скасоване" фіксовані

##редактор розділів
товари мають розділятись по типам. типи можуть вкладатися один в одного

##редактор модицікацій
модифікація - це параметр, який може приймати одне з запропонованих значень, які заздалегіть прописані
у кожного значення має бути його ціна, вона можу дорівнювати 0
значення може бути просто текстовим полем, якшо це вказати додатково - тоді юзер на сайти матиме моливість ввести опис самостійно для замовлення
кожну модифікацію модна використати в різних товарах

##редактор товарів
один товар може бути в декількох розділах
товар має базову ціну без модифікацій
модифікації впливають на загальну ціну товару- базова + ціна варіанта модифікаціі. якшо модифікацій декілька - ціна складається з базовою + кожний вибраний варіант модифікації
